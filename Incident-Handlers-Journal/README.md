# Incident Handler's Journal

**Template from the Google Cybersecurity Professional Certificate (Coursera)**

## Overview
A journal documenting security incidents and hands-on tool activities. Each entry records what happened, the tools used, and key findings, following the 5 W's (Who, What, When, Where, Why) and the NIST incident response lifecycle.

## Entries
| # | Entry | Tool | Focus |
|---|---|---|---|
| 1 | Ransomware attack on a health care clinic | None | Incident documentation, phishing, HIPAA considerations |
| 2 | Analyzing a packet capture | Wireshark | Display filters, packet inspection |
| 3 | Capturing network traffic | tcpdump | Live capture, saving and reading .pcap files |
| 4 | Investigating a suspicious file hash | VirusTotal | IOC analysis, phishing alert triage |

## Key Takeaways
- Clear, factual documentation is critical at every stage of incident response
- Filters are essential for finding relevant traffic in large packet captures
- Threat intelligence tools like VirusTotal help analysts quickly confirm whether an IOC is malicious
